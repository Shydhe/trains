# Trains Nice ZOU, installer l'app

1. Sur github.com, crée un dépôt public nommé `trains` (bouton New).
2. Dans le dépôt : Add file → Upload files, puis glisse tous les fichiers de ce dossier (pas le dossier lui-même). Commit.
3. Settings → Pages → Source : Deploy from a branch, branche `main`, dossier `/ (root)` → Save.
4. Attends 1 à 2 minutes. L'adresse est https://TON-PSEUDO.github.io/trains/
5. Sur ton Android, ouvre cette adresse dans Chrome, menu ⋮ → Installer l'application (ou Ajouter à l'écran d'accueil).
6. Ouvre l'app une fois avec du réseau : ensuite elle marche hors ligne.
